Instructions for the person or AI assistant creating listings
  1. Work through “Ready to post” below. Create one Facebook Marketplace listing (Create new listing → Item for sale) per item.
  2. Copy each field exactly: Title, Price, Category, Condition and Description. Do not change prices or invent details.
  3. Photo: add the item's photo. Use “Download photo” to save it, then attach it in Facebook. If you can't attach files yourself, stop and ask the user to attach it.
  4. Location: . Leave delivery or shipping off, because it's local pickup only.
  5. Before you click Publish on each listing, show the filled-in listing to the user and wait for their OK.
  6. Skip anything under “Already on Facebook”, since those are posted already. Don't create duplicates.
  7. For each item under “Sold”, if it's listed on Facebook, open it in Marketplace → Your listings and choose Mark as sold.
  8. When finished, tell the user which items you posted or marked sold, so the inventory file can be updated.
